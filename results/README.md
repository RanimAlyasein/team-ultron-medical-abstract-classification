# Result tables

These CSV files are the canonical reported experiment records used by the README, benchmark report, figures, and presentation.

- `benchmark_validation.csv`: validation ranking and available locked-test scores
- `final_test_metrics.csv`: aggregate BiomedBERT locked-test metrics
- `biomedbert_test_per_class.csv`: final per-class test F1 values
- `hierarchical_validation.csv`: flat, Stage 2, and combined hierarchical comparison
- `calibration_summary.csv`: final-model validation calibration summary
- `efficiency.csv`: parameter count and Colab T4 inference timing

Blank cells mean the metric was not reported in the supplied project record. They are intentionally left blank rather than estimated.
